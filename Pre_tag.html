Pre Tag

            
        The (<)pre(>) tag in HTML stands for preformatted text.
             Its primary job is to display text exactly as it appears in 
             the HTML source code, preserving all spaces, tabs, and line breaks that browsers normally ignore.

                Special Characters: Even inside a pre tag, you must
                 still use HTML entities for reserved characters like < (<) and > (>)
                     so the browser doesn't mistake them for actual HTML tags.
